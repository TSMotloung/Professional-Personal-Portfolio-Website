Project Brief: Build a Professional Personal Portfolio Website Using AI
Good day AI Skills Acceleration 12 (ASA 12) || JHB Week 12,

 

Your next practical project is to build a Professional Personal Portfolio Website that showcases who you are, your skills, qualifications, certifications, and projects. This portfolio should be something you can confidently share with potential employers as part of your job applications.

 

Project Objective
Create a modern, responsive, and professional personal website using AI-assisted development tools such as Lovable, Bolt.new, v0 by Vercel, ChatGPT, GitHub Copilot, or any similar AI tool. AI should assist you in the development process, but you must understand and be able to explain the code and design decisions.

Your website must include:
🏠 Home page with your professional introduction
👤 About Me section
💻 Technical and soft skills
📂 At least 3 projects with descriptions and technologies used
🎓 Education
📜 Certifications
💼 Work experience (if applicable)
📞 Contact section with your email, GitHub, and LinkedIn
📄 Downloadable CV (optional but recommended)
Technical Requirements
Responsive on desktop, tablet, and mobile devices
Professional and modern UI/UX
Easy navigation
Deployed online using GitHub Pages, Vercel, Netlify, or a similar hosting platform.
Remember, this project is an opportunity to build a professional portfolio that you can continue improving and use when applying for internships and employment opportunities.

 

Project submission: 2PM

Best of luck, and don't hesitate to ask questions if you need guidance.
